# FiverrGrowth Chrome Extension — Safe Briefs Copilot

A lightweight companion extension for Fiverr freelancers that detects inbound Buyer Briefs directly within your active Fiverr web session and automates high-converting proposal generation safely.

## Zero-Ban "Safe Zone" Architecture
- **Uses your legitimate browser session & residential home IP**: No datacenter cloud IP bot flags.
- **Zero credential storage**: We never ask for or store your Fiverr password.
- **Human Pacing Gap**: Built-in 15s–40s configurable safety delay between proposal dispatches so Fiverr algorithms never detect automated burst activity.

---

## How to Install in Chrome (Takes 30 Seconds)

1. Open **Google Chrome** (or Brave / Edge).
2. Navigate to: `chrome://extensions`
3. In the top-right corner, toggle on **"Developer mode"**.
4. Click the **"Load unpacked"** button in the top-left corner.
5. Select this folder:
   ```
   C:\Users\hp-new\Desktop\fiverr-growth\extension
   ```
6. The **FiverrGrowth — Safe Briefs Copilot** extension will appear in your extensions toolbar!
7. Pin the extension for quick 1-click access whenever you are browsing Fiverr.

---

## How It Works With the Web App
1. When you visit `fiverr.com/manage_gigs` or your seller dashboard, the extension automatically inspects incoming briefs.
2. Click **"Sync Briefs"** to send them into your FiverrGrowth web dashboard (`http://localhost:5173/briefs`).
3. In the web app, select which briefs to target, set your safety delay (gap), generate tailored AI proposals, and review before safe dispatch.
